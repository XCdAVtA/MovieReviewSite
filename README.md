# WHATtoWATCH - Movies Admin

Movie review site! 

## Built with

- ASP.NET Core MVC, Entity Framework, SQL Server
- Developed in JetBrains Rider on macOS
- SQL Server runs in Docker

## Running it

1. Start SQL Server in Docker
2. Create the database: `dotnet ef database update`
3. Run the app: `dotnet run`

## Note

- If using docker isn't an option I can make it create its own database
- If using Rider/Mac causes any issues on your end I will switch back to using Visual Studio
